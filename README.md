# 📚 Laboratório de Algoritmos e Lógica de Programação

Repositório destinado ao armazenamento de **atividades, exercícios e trabalhos desenvolvidos durante o Laboratório de Algoritmos e Lógica de Programação**, referente ao **1º período do curso de Sistemas de Informação da PUC Minas – Unidade Betim**.

## 👨‍💻 Autor

**Pedro Vinícius da Silva Costa**

## 🎯 Objetivo

Este repositório foi criado com fins **acadêmicos e de consulta**, reunindo atividades e trabalhos realizados ao longo da disciplina.

Os códigos aqui disponibilizados têm como objetivo registrar a evolução no aprendizado de **lógica de programação e desenvolvimento de algoritmos**, servindo também como material de apoio para futuras consultas e estudos.

## 🧠 Conteúdos trabalhados

Durante as atividades, são abordados conceitos como:

* Lógica de programação
* Algoritmos
* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores matemáticos e lógicos
* Estruturas condicionais (`if`, `else`, `switch`)
* Estruturas de repetição (`for`, `while`, `do while`)
* Contadores e acumuladores
* Vetores e matrizes
* Funções e métodos
* Resolução de problemas utilizando programação

## 💻 Linguagem
